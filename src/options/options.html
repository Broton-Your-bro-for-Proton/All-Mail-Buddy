Normally neither is needed: the add-on asks the server every few minutes which folders changed and loads only those. "Sync all folders now" loads every Bridge folder from the server once; use it after Thunderbird was offline for a long time, or when the Folder column looks wrong for many messages. Diagnosis

All Mail messages that do not have exactly one matching copy in a real folder.

The saved search appears as a folder next to All Mail and lists the messages without a folder, so they can be selected and handled together. It updates when it is opened, so open it again after handling messages. Click a row in the list below to show that message.

Server check

Looks up messages without a folder on the server. Folders whose local message list no longer matches the server are repaired like "Repair Folder" in Thunderbird does it; all other folders stay untouched.

The daily run repairs a folder at most once a week. Folders with changes made while offline are skipped.

Thunderbird only shows subscribed folders. The list compares the server's full folder list with Thunderbird's folders and shows each missing one with its subscription state.
